# 櫻坂46 推し活ノート

## PCで使う

`PC用.html` をダウンロードし、EdgeやChromeで開いてください。Pythonやサーバーは不要です。
リポジトリ全体を保存した場合は `index.html` を直接開くこともできます。

データ・画像・背景は使っているブラウザに保存されます。公開サイトのデータはPC版へ自動で引き継がれません。HTMLファイルだけのコピーには登録データは含まれません。同じブラウザとファイルの場所を使ってください。

## 背景

画面右上の「背景」から画像を選択し、白の濃さを調整して保存できます。「背景を解除」で元に戻せます。

## コードを変更する場合

Node.jsを使える開発環境で、最初に `npm ci`、ソース変更後に `npm run build` を実行します。
`js/app.js` と `PC用.html` は生成ファイルです。編集するソースは `js/main.js` などの各ファイルです。
